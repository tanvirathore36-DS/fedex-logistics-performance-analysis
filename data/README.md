# Dataset

This project uses the SCMS Delivery History Dataset for analyzing logistics and shipment performance.

The dataset contains shipment-level information including delivery dates, shipment modes, freight costs, vendors, countries, and delivery performance indicators.

The raw dataset is not included in this repository. The notebooks document the data cleaning, transformation, exploratory analysis, and feature engineering performed on the dataset.

The Tableau dashboard was developed using the cleaned data prepared during the project.
